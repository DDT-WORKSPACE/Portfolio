# Integration logo sources

Monochrome product marks are supplied by the Simple Icons package, downloaded as individual SVGs from its jsDelivr package distribution. Reproduce using node scripts/prepare-integration-logos.mjs. Production loads local SVG files, not the CDN.

Source: https://github.com/simple-icons/simple-icons

Included in the website: Slack, Notion, Stripe, Shopify, HubSpot, Google Sheets, Gmail, Zapier, n8n and GitHub. Each identifies its respective third-party tool; the page describes integration possibilities and does not claim a partnership or that every account/plan supports every connection.
