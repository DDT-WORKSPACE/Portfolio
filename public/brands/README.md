# Transparent portfolio logos

Background cleanup used the built-in image generation/editing tool, not the CLI. References were the existing logo crops extracted from the supplied project covers. Original crops remain in this directory. The edited PNG originals and optimized WebPs are saved here; the site uses the clean WebPs with true alpha, rather than blend-mode background removal. Walk Throughz retains its original white artwork and is rendered in dark ink with a foreground-only CSS filter on the light website.

Optimize saved PNGs with `node scripts/save-clean-logos.mjs`. The PNGs are project-local; no account-specific source paths are needed.

## talentbadger

Input: `public/brands/talentbadger.webp`  
Saved PNG: `public/brands/talentbadger-clean.png`  
Website asset: `public/brands/talentbadger-clean.webp`

Exact edit prompt:

> Use case: background-extraction. Edit this exact supplied portfolio logo crop for the DevsDen Tech website. Remove the entire opaque rectangular background and all background halos; output a genuinely transparent alpha background. Preserve the original emblem, exact wordmark spelling, letter shapes, proportions and original brand colors; do not invent or redesign anything. Keep only the logo and its integral tagline. Remove any separate "CASE STUDY" caption or clipped caption at the bottom (if present). For Walk Throughz preserve the white lettering and skyline on transparency. Center the complete logo on a tightly padded wide transparent canvas, edges clean and naturally antialiased, no shadow, no backdrop, no extra text. Reference asset: talentbadger.
